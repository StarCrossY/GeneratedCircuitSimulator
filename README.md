# Circuit Simulator —— 电路模拟器

一个使用 **Java** 编写、通过 **自定义 SPICE 风格网表** 描述电路并进行模拟的项目，内置 **共射放大电路（Common-Emitter Amplifier）** 示例。

项目由两部分组成：

- **可迁移核心代码**（`simcore`）：纯 Java 实现，不依赖任何 UI 框架，可独立复用于无图形界面的环境。
- **可视化外部调用层**（`simapp`）：调用核心库执行模拟，并以图形界面 / 控制台方式展示结果。

---

## 特性

- **可迁移核心 + 可视化解耦**：核心 `simcore` 零 Swing/AWT 依赖；可视化 `simapp` 与核心完全分离。
- **子电路（Subcircuit）**：支持 `.subckt ... .ends` 定义与 `X` 实例化，含嵌套展平与端口映射。
- **两种模拟模式**：
  - `直流工作点分析`（`.op`）：**与过程无关**——给定电源等必需变量数值，直接求解电路任意节点电压与支路电流。
  - `瞬态分析`（`.tran`）：**与过程有关**——给定输入信号后，按时间步进求解全过程及各时刻的全部参数。
- **支持器件**：电阻 `R`、电容 `C`、电感 `L`、独立电压源 `V`、独立电流源 `I`、受控源 `E/F/G/H`（电压/电流控制 × 电压/电流输出）、双极型三极管 `Q`（NPN/PNP）。
- **非线性求解**：基于 MNA（改进节点分析）+ 牛顿迭代，内含 gmin 与电压限步阻尼，收敛稳健。

---

- Windows 下提供 PowerShell 构建 / 运行脚本；核心代码可在任意支持 Java 的平台上以纯 `javac` 编译。

powershell -ExecutionPolicy Bypass -File build.ps1

## HDL 模拟基础

本节介绍用文本（HDL/网表）描述并模拟电路时的几个核心概念，帮助理解如何编写网表、如何解读结果。语法细节见下一节 [网表语法](#网表语法-hdl)。

### 1. 网表就是电路的“文本描述”

不需要画电路图，而是用**一行一个元件**的方式把电路写出来。每个元件行包含三部分：**器件名（含类型首字母）+ 所连接的节点 + 参数值**。

### 2. 节点（node）与地（ground）

- **节点**是电气连接点。两根线相交处（电位相同）应使用同一个节点名。
- 相同节点名 = 电气上短路连通；不同节点名 = 相互隔离。
- 每个电路都必须有一个**参考点（地）**，本项目统一写为 `0`（也接受 `gnd`）。所有“节点电压”都是相对地而言，因此地本身不参与求电压。

> 例：`R1 vcc base 27k` 表示电阻 R1 一端接节点 `vcc`、另一端接节点 `base`，阻值 27 kΩ。

### 3. 元件（device / element）

- **无源元件**：电阻 `R`、电容 `C`、电感 `L`，给出两端节点与参数。
- **独立源**：电压源 `V`、电流源 `I`，为电路提供激励（电源/信号）。
- **受控源**：`E/G/H/F`，输出由电路中其它电压或电流控制，用于建立等效模型（如小信号三极管模型）。
- **三极管** `Q`：非线性器件，需 `.model` 指定参数（饱和电流、增益等）。

### 4. 两种分析

- **直流工作点（`.op`）**：只关心“稳定不变”的静止状态——电容视为开路、电感视为短路，直接求解一组代数方程，得到各节点电压与各支路电流。
- **瞬态（`.tran`）**：关心“随时间变化”的过程——把电容/电感用数值积分（梯形法）化为“等效电阻 + 历史源”，逐时间步求解，得到全过程波形。

详见 [两种模拟](#两种模拟)。

### 5. 求解原理（简述）

电路被写成 **MNA（改进节点分析）** 方程组 `A·x = b`，其中 `x` 是所有节点电压与电压源支路电流组成的列向量：

- 线性电路求一次方程即得解；
- 含非线性器件（三极管）时，用**牛顿迭代**在当前猜测点线性化、反复求解逼近真解；
- 为保证收敛，求解器加入了对地微小电导 `gmin` 与节点电压限步（阻尼）。

### 6. 编写网表的步骤

1. 确定参考地（节点 `0`）。
2. 为每个元件起一个名（首字母决定类型），并列出它连接的两个（或更多）节点。
3. 给每根连接线起一个节点名，注意“相同连接 = 相同名字”。
4. 若有二极管/三极管，添加 `.model`。
5. 添加分析指令 `.op` / `.tran`，最后以 `.end` 结尾。

### 7. 最小示例解读

```
VCC vcc 0 12            ; 12 V 电源：正端 vcc，负端接地
R1  vcc b 27k           ; 上偏置电阻（vcc 与 b 之间）
R2  b 0 3.9k            ; 下偏置电阻（b 与地之间）
Q1  c b e QNPN          ; NPN 三极管：集电极 c、基极 b、发射极 e
.model QNPN npn(bf=150) ; 定义 NPN 模型，正向增益 150
.op                     ; 计算直流工作点
.end
```

- `VCC` 在节点 `vcc` 与地之间建立 12 V 电压；
- `R1`、`R2` 构成分压，在基点 `b` 产生偏置电压；
- `Q1` 是受 `b` 控制、在 `c` 与 `e` 之间导电的非线性器件；
- `.op` 让求解器算出 `b`、`c`、`e` 各点电压与各支路电流。

## 网表语法 (HDL)

采用自定义的 SPICE 风格文本格式。**注释**：以 `*` 开头的整行、以及行内 `;` 之后的内容均为注释。

### 1. 标题

```
.title Common-Emitter Amplifier
```

### 2. 器件（Element）

| 器件 | 语法 | 说明 |
|------|------|------|
| 电阻 | `R<名> n1 n2 阻值` | 例：`R1 vcc base 27k` |
| 电容 | `C<名> n1 n2 容值` | 例：`Cin in base 1u` |
| 电感 | `L<名> n1 n2 感值` | 例：`L1 a b 10m` |
| 电压源 | `V<名> n+ n- 波形` | `n+` 为正端，例：`VCC vcc 0 12` |
| 电流源 | `I<名> n+ n- 波形` | 电流从 `n+` 流出、注入电路 |
| 压控电流源 | `G<名> n+ n- nc+ nc- 增益` | 电流 `增益·V(nc+,nc-)` 从 `n+` 流出、注入 `n-`，例：`Gm e c b e 40m` |
| 压控电压源 | `E<名> n+ n- nc+ nc- 增益` | 电压 `V(n+)−V(n−) = 增益·V(nc+,nc-)`，例：`E1 out 0 in 0 10` |
| 电流控电流源 | `F<名> n+ n- 被控支路名 增益` | 电流 `增益·I(被控支路)` 从 `n+` 流出，例：`F1 out 0 Vsen 100` |
| 电流控电压源 | `H<名> n+ n- 被控支路名 增益` | 电压 `V(n+)−V(n−) = 增益·I(被控支路)`，例：`H1 v 0 Vsen 1k` |
| 三极管 | `Q<名> 集电极 基极 发射极 模型名` | 例：`Q1 col base em QNPN` |
| 子电路实例 | `X<名> 引脚... 子电路名` | 引脚顺序须与端口一致 |

> 地节点统一使用 `0` 或 `gnd`（大小写均可）。

受控源提供四种组合，「控制信号」可选电压或电流，「输出」可选电压或电流：

| 器件 | 控制信号 | 输出 |
|------|----------|------|
| `E` 压控电压源 VCVS | 电压 | 电压 |
| `G` 压控电流源 VCCS | 电压 | 电流 |
| `H` 电流控电压源 CCVS | 电流 | 电压 |
| `F` 电流控电流源 CCCS | 电流 | 电流 |

其中电压控器件（`E`/`G`）用一对控制节点给出控制电压；电流控器件（`F`/`H`）通过引用某个电压源名（被控支路）来感知其支路电流。

### 3. 数值后缀

| 后缀 | 倍率 | 后缀 | 倍率 |
|------|------|------|------|
| `t` | 1e12 | `m` | 1e-3 |
| `g` | 1e9 | `u` | 1e-6 |
| `meg` | 1e6 | `n` | 1e-9 |
| `k` | 1e3 | `p` | 1e-12 |
| | | `f` | 1e-15 |

后缀大小写不敏感；兆请使用 `meg`，`m` 表示毫。

### 4. 波形（用于 V / I 源）

| 形式 | 含义 |
|------|------|
| `12` | 直流恒定值 |
| `sin(offset amp freq [相位°])` | 正弦：`offset + amp·sin(2πf·t + φ)` |
| `pulse(v1 v2 [delay rise fall width period])` | 周期脉冲（分段线性） |

例：

```
VCC  vcc  0  12
Vin  in   0  sin(0 0.01 1k)     ; 1kHz / 10mV 正弦
```

### 5. 模型（.model）

定义三极管模型参数（简化 Ebers-Moll）：

```
.model QNPN npn(bf=150 br=5 is=2e-15)
```

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `is` | 饱和电流 IS (A) | 1e-15 |
| `bf` | 正向电流增益 BF | 100 |
| `br` | 反向电流增益 BR | 1 |
| `vt` | 热电压 VT (V) | 0.025852（300K） |

类型取值 `npn` 或 `pnp`。

### 6. 子电路（.subckt）

```
.subckt 名 端口1 端口2 ...
   ... 内部器件（节点名为局部名）...
.ends
```

实例化：

```
X<名> 引脚1 引脚2 ... 子电路名
```

端口（引脚）顺序须与 `.subckt` 声明顺序一一对应；内部节点会自动被前缀重命名以避免跨实例冲突，并支持嵌套子电路。

### 7. 分析指令

| 指令 | 含义 |
|------|------|
| `.op` | 直流工作点分析 |
| `.tran 步长 终止时间` | 瞬态分析，单位秒，例：`.tran 1e-5 0.005` |
| `.end` | 网表结束（可选） |

其他未识别的点指令（如 `.print`、`.plot`、`.option`）会被忽略。

## 两种模拟

### 1）直流工作点分析（`.op`）—— 与过程无关

只需给定电源电压等必需变量数值，求解器直接建立并求解非线性代数方程，得到各节点直流电压与各支路/器件电流（静态工作点）。电容视为开路，电感视为短路。

### 2）瞬态分析（`.tran`）—— 与过程有关

先求 `t=0` 时刻的直流工作点作为初始状态，随后按固定步长 `h` 时间步进；每一步用**梯形积分**将电容/电感转化为伴随模型，再与非线性三极管一起进行牛顿迭代，得到全过程每个时刻的全部参数（节点电压、器件电流等）。

---

## BJT 模型（简化 Ebers-Moll）

端电流以“流入器件”为正方向，端序为集电极 `c`、基极 `b`、发射极 `e`。对 NPN（PNP 通过极性符号 `p=±1` 复用同一组公式）：

```
Ic = IS·(e^(Vbe/Vt) − e^(Vbc/Vt)) − (IS/BR)·(e^(Vbc/Vt) − 1)
Ib = (IS/BF)·(e^(Vbe/Vt) − 1) + (IS/BR)·(e^(Vbc/Vt) − 1)
Ie = −(Ic + Ib)
```

牛顿迭代使用上述方程对三个端节点电压的**解析雅可比矩阵**做线性化，并限制指数参数以避免溢出。

## 示例：共射放大电路

示例网表位于 [`examples/ce_amplifier.net`](examples/ce_amplifier.net)，为电压分压偏置、带发射极旁路电容的共射放大级，封装为子电路 `ceamp`。

### 运行结果（直流工作点）

| 节点 | 电压 | | 电流 | 数值 |
|------|--------|---|------|------|
| V(base) | 1.4926 V | | Ib | 6.44 µA |
| V(emitter) | 0.7971 V | | Ic | 0.966 mA |
| V(collector) | 9.8755 V | | Ie | −0.972 mA |

### 运行结果（瞬态分析）

- 输入 `Vin`：1 kHz / 10 mV 正弦（峰峰值 20 mV）
- 输出 `Vout` 峰峰值 ≈ 1.33 V
- 电压增益 **|Av| ≈ 66**，且输出与输入**反相**（符合共射放大特性）。

## 示例：小信号等效（受控源）

示例网表位于 [`examples/ce_amplifier_small_signal.net`](examples/ce_amplifier_small_signal.net)。它演示了**用受控源 + 电阻网络子结构等效 BJT** 的低频小信号模型（hybrid-π）：

- 用电阻 `rπ`（基极-发射极）与一个压控电流源 `gm·v_be`（集电极-发射极）构成子电路 `ssbjt`，替代非线性三极管；
- 直流电源 `VCC` 在小信号等效中被替换为交流地，偏置电阻因此接在基极与地之间；
- 发射极假设被旁路电容完全短路（中频段），直接接地。

| 等效关系 | 表达式 |
|------|------|
| 跨导 | `gm = Ic / Vt ≈ 40 mS` |
| 输入电阻 | `rπ = β / gm = 4 kΩ` |
| 电压增益 | `Av = −gm·(RC‖RL) ≈ −72` |

运行结果：输入 10 mV 正弦，输出峰峰值 ≈ 1.44 V，**|Av| ≈ 72**，且输出与输入反相——与完整非线性模型的增益（≈66）在同一量级。

## 架构说明

- **MNA（Modified Nodal Analysis）**：未知量 = 非地节点电压 + 电压源/电感支路电流。
- **牛顿-拉夫逊迭代**：线性器件直接写入恒定系数；非线性器件（BJT）在当前迭代点线性化后写入雅可比矩阵与剩余项。
- **收敛健壮性**：对每个非地节点施加 gmin（1e-12 S 对地电导）防止矩阵奇异；对单次迭代的节点电压变化做限步（阻尼）以抑制发散。

## 限制与可能的扩展

- BJT 采用简化 Ebers-Moll 直流模型，未包含结电容 / 渡越时间（`CJE`/`CJC`/`TF`）等高频效应；如需更高频精度可扩展。
- 瞬态使用固定步长梯形积分；更大规模或刚性更强的电路可引入变步长 / 自适应时间步。
- 线性方程组采用稠密高斯消元，本项目规模（几十个未知量以内）足够，若扩展到更大规模可换稀疏求解器。
